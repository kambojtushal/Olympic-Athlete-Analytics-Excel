# 🏅 Olympic Athlete Analytics Dashboard (Microsoft Excel)

## 📌 Project Overview

This project is an interactive **Olympic Athlete Analytics Dashboard** built entirely in **Microsoft Excel**. It transforms raw athlete data into meaningful insights using Pivot Tables, Pivot Charts, calculated metrics, and dashboard visualizations.

The dashboard enables users to explore athlete performance characteristics such as age distribution, BMI, height, weight, sports participation, and nationality through interactive filters.

---

## 📊 Dataset Information

- **Dataset Size:** 2,606 Athlete Records
- **Columns:** 11
- **Tool Used:** Microsoft Excel

### Dataset Fields

- Athlete Name
- Sport
- Nationality
- Age
- Weight (kg)
- Height (cm)
- BMI
- Weight Level
- Height Level
- Age Group
